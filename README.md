# 🔐 Gerador de Senhas em Python

Gerador de senhas desenvolvido em **Python**, permitindo escolher o tamanho da senha e quais tipos de caracteres serão utilizados.

## 🚀 Tecnologia utilizada

- Python

## ✨ Funcionalidades

- Definição do comprimento da senha
- Opção de incluir letras
- Opção de incluir números
- Opção de incluir símbolos
- Validação para impedir a geração sem nenhum tipo de caractere selecionado
- Geração aleatória da senha

## ▶️ Como executar

1. Tenha o Python instalado.
2. Baixe ou clone este repositório.
3. Execute no terminal:

```bash
python index.py
```

## 📚 Objetivo do projeto

Projeto desenvolvido para praticar funções, condicionais, entrada de dados e os módulos `random` e `string` do Python.
